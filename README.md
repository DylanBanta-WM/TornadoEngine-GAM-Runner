# Tornado Engine GAM Runner

A [Tornado Engine](https://github.com/DylanBanta-WM/TornadoEngineCore) module: run GAM commands from the website, at /gam-runner.

- Two permissions: "Run read-only GAM commands" (info, print, show and report) and "Run any GAM command".
- Output can be downloaded. Who ran which command is recorded; the output isn't kept.
- Commands share the GAM card's limits.

Needs the GAM module.
